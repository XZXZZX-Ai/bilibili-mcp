## 中文

- 修复 B 站 AI 字幕偶发串到其他视频的问题：当字幕末段结束时间比可信的目标分 P 时长多出 5 秒以上时，拒绝这份字幕并走现有无字幕回退。（#80、#81）
- 感谢 @eeeggplant 提供复现案例、提交 PR #81 的时长拦截修复和回归测试！
- 时长不可信时不会仅凭时长拒绝；时长正常但内容串台的情况仍可能漏过。

## English

- Rejects a platform AI subtitle when its last segment ends more than five seconds beyond the target Part's trusted duration, using the existing missing-subtitle fallback for clear cross-video content. (#80, #81)
- Thanks to @eeeggplant for the reproductions, the duration guard in PR #81, and regression tests!
- The guard is inconclusive without a trusted duration; semantically wrong content within the duration may still pass.
